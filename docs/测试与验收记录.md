## 三、验证中发现并修复的真实缺陷（均已重新编译验证）

1. **ForEach 键不含状态导致 UI 不刷新**
   现象：执行联动后日志已显示"灯 关→开"，但设备卡片按钮仍显示"已关闭"（取证截图 `bug-设备状态未刷新.jpeg`）。
   原因：`ForEach` 的 `keyGenerator` 使用 `d.id` 与 `String(r.id)`，键值不变时 ArkUI 不重建子组件。
   修复：设备键改为 `d.id + ':' + d.on`；规则键改为 `r.id + ':' + r.enabled + ':' + r.priority + ':' + r.name + ':' + r.deviceId + ':' + r.action + ':' + r.conditions.length`。修复后同一流程设备显示"已开启"。
2. **Select 不显示当前选中值**
   现象：四个下拉框只显示"▼"，看不到"温度 / > / 空调 / 开启·打开"。
   原因：`Select` 缺少 `.value()` 绑定。
   修复：四处补 `.value()`，并新增 `fieldLabels`、`opLabels`、`deviceLabels`、`actionLabels` 四个标签数组。
3. **补充提交保护**：`commit()` 增加 busy 分支提示"正在保存上一步操作，请稍后重试"，避免连点期间操作被静默丢弃。

## 四、环境限制（非应用缺陷，如实记录）

- 模拟器 `uitest` 的 `uiInput click` 无法命中 `Select` 弹出浮层（4 个不同 y 坐标均失败，浮层不出现在 `dumpLayout` 中），因此"目标设备 / 动作 / 条件字段"下拉无法用脚本改选；UI 自动化改用纯文本框路径（规则名、阈值、优先级）完成新增与修改。
- 设备端无 `screenrecord`（`/bin/sh: screenrecord: inaccessible or not found`），录屏改用桌面端窗口录制完成。
